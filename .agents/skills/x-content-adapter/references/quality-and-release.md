# X 适配层发布门禁 / 多轮审查协议

## 两张独立审查单
I. 编辑质量与原创实质：符合用户选题和读者价值；作者自己的观点/选择/证明在哪里；每条都兑现具体信息；没有捏造个人经验；事实能追溯；与本账号以前发布的材料不机械重复；保留作者声音和被要求保护的段落。
II. X 奖励资格与平台安全：版权/转载/许可、是否未经允许搬运、是否低贡献聚合、AI 生成及真实声明边界、误导性断言、任何自动化创建/发布、赞助披露、诱导互动、平台编辑器最终长度/可发权限。合格曝光只作为平台历史回报指标，不是稿件预估得分。

## 发布前状态机
RESEARCHED（已核素材） → DRAFT（完整草稿） → NEEDS_REVIEW（人工核稿/版权/权限待核） → APPROVED（用户明确确认） → PUBLISHED（用户真实发布证据）。
BLOCKED（版权侵权、恶意伪造、自动生成发布刷量、涉嫌复制）允许从任何环节产生；只能移除风险再回到核稿，不得软件自动“规避判定”。
程序结构校验通过 ≠ 官方收益资格、稿件审美通过、用户批准或作品已发布。

## 三轮强制复核（正式启用前）
第 1 轮｜政策准确性：每条被称为“平台要求”的说法有 X 官方链接；其余案例心得标编辑假设；准确区分账户申请/奖励内容曝光、长帖/Articles、普通自动化许可/奖励资格。
第 2 轮｜内容质量：取有事实核查的工具稿、实测图文、个人短观点、Thread、连贯长文五种真实/假设示例，按用户认可的自然语言、原稿保真、足够知识增量审，不复制范文。
第 3 轮｜回归与接入：核新 Skill 入口、文件引用和基础 Skill 路由、路径存在，至少运行 references/regression-cases.md 的全部正反场景；失败需修后再审，绝不能说“正式上线”。
启用后的真实运营效果仍需有样本量、相近窗口的作品对照，尤其 90 天滚动有效曝光不可按单帖精确归因。

## 关键硬阻断与提示
- HARD STOP：明显抄袭、未经授权重传版权媒体、要求自动化创建/发布并保证奖励、伪造亲测/后台截图或购买流量。
- REVIEW BEFORE APPROVAL：版权未知、事实来源矛盾、图示误称亲测、赞助未披露、长文/Articles 权限不明、用户未实质审核 AI 草稿。
- EDITORIAL CHOICE：首屏行数、图数、Thread 长度、话题标签、最佳发布时间、格式配比。所有这些属于可测试策略而非官方奖励计数规则。
- 对用户提供的真实结果不能改写成公式：来源/时间窗/指标名/草稿状态均保持可追溯。

## 数据记录和反馈闭环
- 发布证据：账号、作品 URL、日期与时区、形式、主题、真实性/来源边界、内容状态。
- 普通传播：同平台 24h 与 7d 的曝光、赞、转发、书签、有效提问、粉丝净增；分清公开快照与后台。
- 奖励：从 Creator Studio 获取账户“最近 90 天”的合格曝光累计及认证粉丝数量，标截图日期/时间窗/字段名；不要当单帖归因，不设虚构的 2%=正常或 5%=目标。
- 对比同账号/相近曝光时间的不同题型，不把大号、高曝光英文帖等同于本账号未来表现。
- 每 7–14 天复核实际样本一次，发现错误及时迭代文案和模块；平台政策发生变更即时复核。
- 只有人工明确批准写入正式结果，Google Docs/Sheets 每次写后必须读回核验。

## 交稿模板（外层说明，不进入复制正文）
1. 推荐形式与一句理由。
2. 主稿（完整，直接复制；Thread 清楚区分每条；Article 标题/正文）。
3. 价值说明：具体兑现的主导价值、对谁有用、可能被保存/讨论的原因（注明推测）。
4. 审核小结：已核事实及来源、原创贡献、是否本人亲测、素材权利/图像标注、平台长度与权限风险。
5. 状态及用户需完成的动作：待审/待人工发布/已发布及证据。不要在用户没要求时提供长篇流水账。
