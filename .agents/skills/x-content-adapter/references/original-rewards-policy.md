## A. 资格要求（申请时的账户级门槛）
必须逐项核对：所在国家/地区可用；18+；账号符合政策、Personal 或 Business；有效的 Premium / Premium+ / Premium Business（或官方明确列出的对应 X Subscription 可用层级）；过去 90 天至少 500,000 个来自已认证用户首页时间线的曝光（不计回复）；至少 500 个已认证粉丝；持续发布原创内容。满足不等于自动获批，需审核。
提醒：自己的 Premium Basic 不能作为当前申请资格；但 Premium Basic 观众产生的观看可能属于收益规则中的合格曝光。
账号普通总粉、总曝光、转赞收藏、媒体浏览等都不能直接代替以上门槛。用户曾报 7.7K 有效曝光，应核对 Creator Studio 具体字段、同一时间窗口和认证粉丝，不假定已验证。

## B. 奖励合格曝光（内容级规则）
官方定义：Premium Basic / Premium / Premium+ / Premium Business 用户在 Home Timeline 中对同一原创内容的唯一曝光，且帖子至少 50% 可见。排除同一账号同帖重复、广告/推广、人为制造及欺诈曝光。
限制：官方没有公开逐帖详细资格分解或 50% 所依据的具体卡片裁切口径。不能说“显示一半预览卡片即可计入”，不能提供确定的最佳图片尺寸或必成钩子。可优化首屏明晰与信息可读性，但必须标为编辑假设。
账户申请门槛的“已认证用户首页曝光”与奖励正文“Premium 用户唯一曝光”等词汇有官方分别表述，除非后台说明，不断言二者数值一一对应。
回复不计入申请曝光门槛；不能把回复总阅读量用来冲门槛。
合格曝光由平台统计，本 Skill **不能检测、预测或认证**任何单帖是否产生合格曝光。

## C. 原创及版权审核
官方接受真实评论、分析、创意和本人的声音/经验；不接受复制、轻微修改、缺少实质新框架的聚合或他人跨平台搬运。
工具合集需自己做真正有信息增量的用途框架、选型、限制、原创比较或有证据的结论；不能用“加几个主观形容词”规避聚合风险。
原创奖励规则与版权规则不同：即使有原创分析仍可能侵犯第三方图片、音乐、样片和人物肖像。无法确认权利时优先链接原作品、嵌入 X 原帖（若平台支持）或寻求许可，不能直接下载重传。
区分官方演示、原作者成果、用户本人实测、自己生成的概念示意和未知。赞助/付费合作另须遵守 X 广告及付费披露要求。

## D. 自动化边界（非常重要）
Original Content Rewards 官方明确列出 “Was created or posted using automated means” 作为可能不合格的内容，也禁止机器刷赞、刷关注、刷曝光和反复诱导点赞/回复/收藏/转发。
通用的 X 自动化规则在别的情境可能容许合规自动信息广播；它不保证符合 Original Content Rewards 的更严格资格。因此本工作流不得无人介入批量自动生成、直接自动发帖、脚本刷量、复制模板批量洗稿。
允许 AI 协助信息研究、草稿、校对，不代表官方已明确保证奖励资格。用户应提供真实判断、人工实质性审改、最终在平台亲自发布。即使这样仍是平台审核结果为准。
不要把全部账号内容做成“教人领取收益、最大化分成”的单一主题；官方列为不合格内容类别之一。

## E. 操作检查，严禁伪指标
- 内容/出处：本人原创实质性贡献？来源可追溯？是否复制或低贡献堆叠？
- 操作风险：任何自动创建、自动发帖、批量伪互动、统一话术？有即停止相关功能。
- 媒体许可：自有、明确许可、引用原帖还是未知？未知不得宣称许可。
- 所有数字：来自 Creator Studio 后台/账号分析/第三方公开快照/作者自报哪种？时间和窗口是否对应？
- 账号资格：Premium 档位、认证粉丝、地区、账号状况是否有证据？
- 不给 50% 可见率评分、合格曝光转换率的行业“正常区间”、保底曝光、最佳算法时间或收益预测。
- 规则复核责任：官方变更优先更新本页，再修订模块审稿条款。
