# AI Topic Research · 选题阶段 v1.1（2026-10-19 生效）

## 职责与权威上下文
只负责来源研究、需求验证、原创角度、内容价值审核、排序和反馈，不负责自动写稿、生成媒体、发布。已明确指定的选题或已有初稿尊重用户意图，做必要事实核验后进入出稿系统，不强制重走发现流程。
- 项目总控：https://docs.google.com/document/d/1Jw9zjaNnEy9ixfuNSinf7ZL3Zh72wF7otLPD3rdyGZc/edit
- 运营台账：https://docs.google.com/spreadsheets/d/1P9hGNDJmwil7KnWmUm7Y2IlPp1BRK3-erPdQ7fhHyQA/edit
- 每次先读最新决策、选题池、AICG选题池、AICG来源库、需求证据库、内容数据、账号内容审计及发布状态；台账优先于旧聊天。跨天去重，不复活用户明确否定题。既有 GitHub Actions 工作流和北京时间约09:30日报不重复创建。

## 最高优先级：所有选题必须有四大价值
用户于2026-10-19再次确认，所有未来题材——教程、AI观点、宝藏工具、Prompt/Skill、AICG图片/视频、开源项目、AI行业变化——都必须有以下**明确交付物**，不是靠形容词打分。

1. **吸引力**（25分）：第一屏或前三秒有具体悬念、反差、痛点、收益或令人惊讶的画面；写出准确、自然、不骗点击的开头；不得只用“大模型又更新”式空标题。
2. **收藏价值**（30分）：读者能够保存一个真实可用的东西，如 Prompt、参数、完整工作流/节点图、可复用模板、工具入口+适用边界、清单、操作步骤、判断框架或原创方法。写出“收藏后能拿走什么”。仅能看一眼的作品不合格。
3. **学习价值**（25分）：读完能完成具体操作、理解可复验技巧、避免真实错误、做出更明智决策或获得有论证的独立观点。给出前提、步骤/推理链、边界、验证方式；不止于搬运截图。
4. **传播潜力**（20分）：必须说明读者为什么会分享或讨论（强反差、可展示前后对比、切身需求、时效或原创认知），并按证据分级：
   - A verified_viral：有**同一作品**在真实社交平台、可回查、具体时间点的浏览/赞/转发/收藏等数据与直达原帖；可以说明哪一个平台，但不能说全网爆火；截图/第三方快照说明来源与不一致。
   - B fresh_potential：最新官方/原作者一手链接、可核实首发或更新日期、明确的新意及受众传播机制；尚无足够热度时只标编辑预测，不得冒称爆火。
   - C unverified：缺少可靠时效/传播证据，限学习资料，不进入正式选题推荐。

### 分数与门槛
四项编辑评估：吸引力25、收藏30、学习25、传播20，共100；**总分≥85，并分别达到吸引力≥20、收藏≥24、学习≥20、传播≥14**才能进入正式推荐（上述分项下限防止高分掩盖短板）。分数必须由审稿人依据实读材料显式填写；模型、GitHub抓取、站点点赞不能自动判定或捏造人工评分。未填分仅算研究候选。准确性/可用性/版权/平台规则任一硬伤，仍然否决；门槛为内部编辑原则，不代表平台算法或可预言流量。

## A. Customer Research：追溯真实问题
1. 优先可回查的原始用户讨论/评论、原创技巧、官方功能说明、实际可运行工作流。官方发布≠用户需求；产品拥有功能≠用户亲测可用。
2. 保存原作者、平台、原始作品/教程深链、首发和更新时间、真实可读/可见范围、原话或准确释义、适用对象/条件、来源限制和权利许可。
3. 跨日、跨平台按同一问题/同一原作品/同一Prompt或工作流排重；只有新验证、新角度或新实操增量才可再次推荐。
4. 对用户痛点，独立语境数1=低、2=中、≥3=高（编辑证据分层，不是统计结论）；同帖多评论不可冒充独立语境。网络搜索摘要/模型元数据是线索，未读全文不能当成完整教程。

## B. SPARK：从证据到可收藏的具体选题
- Stock：真实需求、专业教程、原创作品、官方文档、作品站带Prompt/Workflow、具来源的新热点。
- Produce：先描述可交付物，再构思实用/决策/认知/情绪观点，允许图片、视频、推文与工具收藏，不强制只做某一种媒体。
- Angle：与历史及竞品相比，必须新增操作方法、参数、可复制素材、正确性边界、独立判断或视觉叙事；避免泛泛工具榜、空洞产品功能、同类普通特效。
- Rank：**先过四价值硬门槛**，再参考旧版研究排序（需求25/价值25/时效20/差异化15/受众10/可行5）；两套分数不可混称。
- Kick-test：明确原作作者、可打开资料、学习交付物、已实测/作者自述/官方宣称区分、必要复现实验、收费/配置/版权/AI标识与平台适配。

## C. AICG 作品及技巧专项
从成熟一手阵地找：Higgsfield Community 项目/Shot（留意Prompt是否公开）、Midjourney Explore Prompt/参数/Style code、ComfyUI官方工作流JSON、Runway Academy、Google Flow TV、Runway AI Festival、Tensor.Art Remix、Krea Community、Luma等原作者页；20名X作者与18个专业站点仅是基线，并非上限。
- 优先“好作品＋确切Prompt或可下载工程”、“高价值生图视频技巧＋步骤＋前后对比”、“顶尖品牌/获奖作品＋实证制作解剖”。三者都要能兑现收藏和学习价值。专业获奖作品若不公开方法，可以作为审美参考，不硬称可复刻教程。
- 实际**观看原创媒体或可信原作者公开预览**才能进行视觉高分判定：画面/前三秒45、原创性20、公开方法及可复刻性15、跨平台10、来源/合规10；视觉≥40/45且总分≥85/100才算“视觉精品”。四价值审核**额外适用**，不是把两套100分相加。
- 只取得作品标题、链接、模型参数、媒体URL元数据，或未亲见画面 => 标记“视觉未核验/学习资料”；不要虚构光影、镜头、分数或最强前三秒。
- 不能以灾难规模、普通转场、像素化、拟音功能或软件演示自动认定高视觉质量；静态图同样应得到公平审查，不只推荐视频。
- 首选最近24小时，最长72小时需标明；教程/专业参考可扩大窗口但要明确原发布日期，不冒充最新首发。
- 发布/商业用途核实图片、Prompt、模型、音视频、人物肖像、商标与引用许可；禁止未经授权复制原片去水印再上传。

## 一票否决与研究候选边界
以下任一即不准称“优质正式选题”：四价值无具体理由/交付物；无可追溯一手来源；无真实资料可教用户；仅靠形容词和普通漂亮图；热度被虚构；以前遭用户否定且未加新证据；版权/安全风险未控制；只展示产品却假称亲测；无人工评分却报高分。
若来源充足但待实测，标研究候选或B类传播潜力，不冒充“已经爆火”。若用户一次索要20条，优先提供真正合格的条目；不足时明确数量，可**另列待核线索**但不能混入正式精品名单。

## 输出契约：每条必须完整
- 可点击的**原始作品或教程**深链与原作者、准确发布日期、内容类型、证据A/B/C及可见范围。
- 开头吸引点（第一屏/前三秒）、明确收藏品、学会的具体技巧或独立判断、传播证据或机制、目标受众、跨平台原创改造角度。
- 提示词/参数/工作流真实公开状态及入口、工具门槛/成本与版权限制、人工四价值分数（未评分写“未评分”）、下一步核验。
- 不堆网址、不报无法核实的浏览量，不因用户要求数量强行凑数。报告Top 3并选唯一下一步。未确认选题不提前写稿；没有用户实际发布反馈，播放/收藏/收益未知。

## 现有执行工具与记录
- 无需新增自动化：`python social-topic-radar/topic_quality_gate.py radar --output-dir social-topic-radar/output` 只审计公开信号，永不自动批准。
- 人工审查档案采用 [审核 JSON 格式](references/review-schema.md)，运行 `python social-topic-radar/topic_quality_gate.py review --input dossier.json --history history.json --output-dir ./topic-output`；历史拒绝及已选题键来自Google Sheets，不假装GitHub Actions读得出私有Drive。
- 测试 `python -m unittest discover -s social-topic-radar/tests -v`。审查分数由真人确认或按实际证据显式录入，自动规则不保证传播。
- 必须将用户明确确认的规则、结果与理由更新同一项目总控、Sheet“决策与交接”，写后读回。选题只有真正通过审核且不重复才入对应选题池；草稿≠发布。
- 来源受限须诚实报告；不借用账号Cookie/绕登录/伪造用户评论及指标。
