# 自由学习｜AI 全领域应用与交付学习系统

> 状态：课程基础设施 v0.1 · 建立日期 2026-10-17 · 当前为公开仓库中的非私密课程骨架

## 目标
本课程旨在培养能够不手写底层代码，最大化利用现有 AI 解决实际问题的高级应用者。涵盖通用 AI 协作、AI 赋能办公、AIGC 图像视频音频、自媒体、自然语言驱动的网站/APP 开发、Agent/Skills/MCP/自动化，以及跨行业的真实项目交付。

## 不可更改的学习约束
- 所有课程中文授课、学习互动均在 ChatGPT 项目「自由学习」中进行。
- 不安排 Python/JavaScript 等语言的手写编程训练；允许 AI 生成、修改、测试、部署代码。
- 学习必要的产品、数据、权限、部署、安全、验收等非代码概念。
- 每次只教一个可闭环课时：资料核验 → 教学 → 演练 → 独立交付 → 审核 → 记录。
- 不得声称读完/看完未实际可获取的课程或视频。
- 根据作品验收与迁移能力晋级，而不是看完即算学会。

## 重要的部署说明
目前位于公开仓库 `chenyang-99/codex` 的独立目录，**并非独立私有仓库**。这里仅存放通用课程、空白学习状态和公开许可的来源引用，不保存私人学习反思、原始作业、成绩、敏感文件、账户数据或任何密钥。准备开始保存个人作业之前，应迁移至独立私有仓库，并确认 GitHub 写入权限。

## 使用方式
1. 在「自由学习」项目对话中说“继续学习”，导师先读取最新 PROGRESS.json、当前课时和对应课源。
2. 教师在来源完整性不足时不得假装已观看原课；必要时采用并标识替代教材。
3. 完成一个课时后，教师先评审，再把经过确认的结果写入进度（需安全存储位置），读取复核，最后明确报告写入是否成功。
4. 本公开原型不会自动在 ChatGPT 项目对话与 GitHub 之间同步；每次必须有实际读写操作。

**原则：学习过程可信、成果可检验、进度可恢复、知识可迁移。**
