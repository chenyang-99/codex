# AI Learning System: Agent Instructions

Scope: files under `ai-learning-system/`. These rules supplement, not replace, the parent repository AGENTS.md.

- Source-of-truth: always read `README.md`, `TEACHING-CONTRACT.md`, `PROGRESS.json` and the current lesson before teaching.
- The existing repository is PUBLIC. **Never write private personal learning data, scores, student essays, user account identifiers, or credentials here.**
- Curriculum is Chinese, 48 weeks, no manual coding required of the learner. AI may generate code; learner handles goals, validation, risk, safety and release decisions.
- Do not claim that external full videos/paid course materials were accessed when only a public syllabus was viewed.
- Each lesson requires material audit, explicit objectives, evidence-based teaching, independent practice, real deliverable assessment and a verified durable progress write.
- Do not claim a GitHub sync succeeded until read-back verification. Prefer editing only this directory unless user explicitly requests otherwise.
- Document source access changes and course revisions. Respect licensing and copyrighted course materials.
