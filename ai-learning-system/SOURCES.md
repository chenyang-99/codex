## 课时素材进入教学的验证级别
- **A 级**：该节完整文本/讲义或逐字稿 + 关键视觉演示已实际取得并核对。可以对原节做完整结构化讲解。
- **B 级**：可靠部分资料已取得，但某些演示画面/步骤未验证。仅教已经核实的部分，补充自身示范并标明局限。
- **C 级**：只有课程介绍、大纲或目录。不得声称已学习完整课时；可改用替代公开权威教材教授对应能力目标。
- **D 级**：访问失败/需认证/付费且尚未取得授权。不得编造课程内容；如需该原课，请用户自行合法提供教材/字幕/链接。

## 提取视频课程的决策树
1. 可获得课程官方逐字稿/字幕/文稿 → 核对课时范围、时间戳、代码/图表/屏幕演示缺口。
2. 合法取得视频文件 → 使用当前可用媒体工具检查音画；若工具不支持整段视频，明确说明覆盖不足。
3. 只有公开视频链接 → 先测页面内容和字幕可否获取；不可推断具备下载及完整解码权限。
4. 需要登录/付费 → 仅在已授予可用访问权限的情况下尝试，不绕过平台限制。
5. 只有大纲 → 标记 C，不做“原课已观看”式总结。
