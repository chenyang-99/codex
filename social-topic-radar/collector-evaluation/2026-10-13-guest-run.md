## 持续运行限制

- 本仓库的 GitHub Actions 是短时、临时云主机，不是全年在线独立 VPS。
- 抖音 v5 真实访客池需要 browser-rpc、Postgres + TimescaleDB、Redis、API 和 worker，持久存储；官方完整建议是 4 vCPU/8 GiB，不能把 Compose 校验视为服务已启动。
- 小红书的游客页面目前失败，不继续重复请求登录限制的接口，也不用个人账户/扫码/主号 Cookie。
- 原选题雷达仍每天在 GitHub Actions 运行，已验证的 B 站/V2EX 评论可作为中文用户痛点证据；不得归属给小红书、抖音。
