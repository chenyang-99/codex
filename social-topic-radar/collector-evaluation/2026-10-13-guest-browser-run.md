## 持续推进原则
- 每个新数据入口必须以原帖可验证 URL + 真实返回记录 + 评论文本与采样数确认，不能把 GitHub CI 绿灯作为采集成功。
- 优先利用公开 API、明确授权的访问方式及普通游客浏览，不反复触发 `-101` 或风控，禁止个人主账号、验证码绕行及付费 API。
- 定期研究新开源项目，但拒绝只有“无需登录”营销文案、实际上需要商业 Token 的伪开源 API 包装。
- 已启用每 6 小时问题攻关自动检查；实质突破时再通知。
