- 因已遇到明确登录墙/访问限制，不能继续用频繁更换游客标识、IP 或验证码绕过手段取得数据。

## 其它免费服务评估

- `SocialCrawl` 提供小红书搜索、评论 API 文档，但要求 API Key 和开通免费账户；并非可以直接拿来在当前 GitHub 无人操作调用的免费接口。
- Apify `scrapewise/xiaohongshu-scraper` 文档明确指出：不用账号时不支持关键词搜索和评论，无法满足全链路。
- `MediaCrawler` 与多个 XHS CLI 的完整评论功能依赖浏览器登录状态，不符合用户约束。
- Hugging Face 有一部分历史小红书内容和评论公开数据集，但它们不是**2026 年当前 AI 赛道关键词热门、完整评论**；不可据此宣称平台实时采集成功。
